# あまた堂 再生ツール

BOOTHの「あまた堂」で頒布しているマーダーミステリーを、スマホだけで遊ぶためのツールです。

https://new1u2sbf-ai.github.io/amatado/

## 使い方
1. BOOTHで購入したzipを、スマホに保存します（iPhoneは「ファイル」アプリ、Androidは「ダウンロード」）
2. このページを開き、「zipファイルを選ぶ」でそのzipを選びます
3. 共通シート、自分のキャラクターシート、進行アプリを開いて遊びます

zipの中身は端末の中だけで開き、どこにも送信しません。このリポジトリには作品のデータは含まれていません。

## 使っているもの
- [JSZip](https://stuk.github.io/jszip/) 3.10.1（MIT License）
- [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174（Apache License 2.0）

ライセンス表記は `vendor/` の各ファイルの先頭にあります。
